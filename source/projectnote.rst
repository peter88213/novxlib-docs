=====================
The <PROJECTNOTE> tag
=====================

.. admonition:: <PROJECTNOTE>
   
   Purpose
      Defines a project note.

   Attributes
      - `id <#the-id-attribute>`__
      - `color <#the-color-attribute>`__

   Content
      - `Title <title.html>`__
      - `Desc <desc.html>`__
      - `Link <link.html>`__

The id attribute
----------------

This attribute is required. The project note ID consists of the
project note prefix **pn** and a number.

Example: ``pn13``

The color attribute
-------------------

This attribute is optional.
The color is specified according to the tkinter conventions
as a hexadecimal RGB value.

Example: ``#ffffff``
